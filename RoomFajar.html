HTML Fundamentals

Materi HTML dari dasar.

Pelajari struktur halaman web, elemen, atribut, form, semantic HTML, dan praktik dasar melalui contoh kode yang bisa langsung dicoba.

01

Apa itu HTML?

HTML (HyperText Markup Language) digunakan untuk menyusun struktur dan konten sebuah halaman web.

  • HTML mengatur struktur dan makna konten.
  • CSS mengatur tampilan dan visual.
  • JavaScript menambahkan interaksi dan perilaku.
Konsep sederhana: HTML adalah kerangka halaman web yang berisi elemen seperti heading, paragraf, gambar, link, dan form.
02

Struktur dasar HTML

Dokumen HTML umumnya dimulai dengan deklarasi doctype, lalu memiliki elemen <html>, <head>, dan <body>.

<!DOCTYPE html>
<html lang="id">
  <head>
    <meta charset="UTF-8">
    <title>Halaman Saya</title>
  </head>
  <body>
    <h1>Halo Dunia!</h1>
    <p>Belajar HTML.</p>
  </body>
</html>
03

Elemen & atribut

Elemen membentuk bagian halaman, sedangkan atribut memberikan informasi atau konfigurasi tambahan pada elemen.

<a href="https://example.com">
  Kunjungi website
</a>

<img src="foto.jpg"
     alt="Foto profil">

<input type="text"
       placeholder="Nama lengkap">
04

Semantic HTML

Elemen semantic membantu memberikan arti yang jelas pada struktur halaman dan membuat dokumen lebih mudah dipahami.

  • <header> — bagian kepala halaman.
  • <nav> — navigasi utama.
  • <main> — konten utama.
  • <section> — kelompok konten.
  • <article> — konten mandiri.
  • <footer> — bagian penutup halaman.
05

Heading, paragraf & link

Elemen teks dasar merupakan fondasi untuk menyusun informasi agar mudah dibaca.

<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<p>Ini adalah paragraf.</p>

<a href="#html-course">
  Pelajari HTML
</a>
06

Form HTML

Form digunakan untuk menerima input pengguna seperti nama, email, pilihan, dan pesan.

<form>
  <label>Nama</label>
  <input type="text" name="nama">

  <label>Email</label>
  <input type="email" name="email">

  <button type="submit">
    Kirim
  </button>
</form>
Programming Languages

Materi bahasa pemrograman.

Pelajari konsep dasar enam bahasa populer melalui materi singkat, konsep penting, dan contoh kode yang mudah dipahami.

Py

Python

Bahasa yang mudah dipelajari dan banyak digunakan untuk automation, data, AI, backend, dan scripting.

  • Variabel dan tipe data: str, int, float, bool.
  • Kondisi menggunakan if, elif, dan else.
  • Perulangan menggunakan for dan while.
  • Fungsi dengan def dan parameter.
  • List, dictionary, tuple, set, module, dan dasar OOP.
nama = "Fajar"

def sapa(nama):
    return f"Halo, {nama}!"

print(sapa(nama))
Latihan: Buat program kalkulator sederhana yang menerima dua angka dan operator.
JS

JavaScript

Bahasa pemrograman utama untuk membuat halaman web interaktif, serta dapat digunakan di backend melalui Node.js.

  • Variabel dengan let, const, dan tipe data.
  • Operator, kondisi, perulangan, dan function.
  • Array, object, dan method seperti map serta filter.
  • DOM untuk mengubah elemen HTML.
  • Event, asynchronous JavaScript, Promise, dan dasar API.
const nama = "Fajar";

function sapa(nama) {
  return `Halo, ${nama}!`;
}

console.log(sapa(nama));
Latihan: Buat tombol yang mengubah teks dan warna sebuah elemen HTML ketika diklik.
Ja

Java

Bahasa general-purpose berbasis OOP yang banyak digunakan untuk aplikasi enterprise, backend, dan berbagai platform.

  • Variabel, tipe data, operator, dan input/output.
  • Percabangan if/switch dan perulangan.
  • Method, class, object, constructor, dan encapsulation.
  • Inheritance, polymorphism, dan interface.
  • Collection seperti ArrayList dan dasar exception handling.
public class Main {
    static String sapa(String nama) {
        return "Halo, " + nama + "!";
    }

    public static void main(String[] args) {
        System.out.println(sapa("Fajar"));
    }
}
Latihan: Buat class Student dengan atribut nama, umur, dan method untuk menampilkan data.
C+

C++

Bahasa berperforma tinggi yang digunakan untuk sistem, game, aplikasi intensif, dan software yang membutuhkan kontrol sumber daya.

  • Variabel, tipe data, operator, dan input/output.
  • Percabangan dan perulangan.
  • Function, array, string, dan reference.
  • Pointer dan dasar pengelolaan memori.
  • Class, object, inheritance, STL, dan template dasar.
#include <iostream>
using namespace std;

int main() {
    string nama = "Fajar";
    cout << "Halo, " << nama << "!";
    return 0;
}
Latihan: Buat program untuk mencari nilai terbesar dari beberapa angka menggunakan array.
PHP

PHP

Bahasa server-side yang digunakan untuk membangun website dinamis, aplikasi web, dan backend.

  • Syntax PHP, variabel, konstanta, dan tipe data.
  • Kondisi dan perulangan.
  • Function, array, dan associative array.
  • Form handling dan dasar session.
  • OOP PHP, database, dan konsep backend dasar.
<?php

$nama = "Fajar";

function sapa($nama) {
    return "Halo, " . $nama . "!";
}

echo sapa($nama);
?>
Latihan: Buat form login sederhana dan tampilkan pesan berdasarkan input pengguna.
Go

Go

Bahasa yang dirancang sederhana dan efisien, banyak digunakan untuk API, cloud service, backend, dan sistem terdistribusi.

  • Variable, constant, tipe data, dan struktur program.
  • Kondisi, perulangan, dan function.
  • Array, slice, map, dan struct.
  • Method dan interface.
  • Goroutine, channel, error handling, dan package dasar.
package main

import "fmt"

func sapa(nama string) string {
    return "Halo, " + nama + "!"
}

func main() {
    fmt.Println(sapa("Fajar"))
}
Latihan: Buat REST API sederhana dengan endpoint untuk menampilkan daftar data.
